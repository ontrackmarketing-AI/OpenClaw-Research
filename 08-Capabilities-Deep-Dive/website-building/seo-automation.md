# SEO Automation for Generated Websites

## Overview

Every website OpenClaw generates must be SEO-optimized from day one. Unlike traditional web development where SEO is an afterthought, automated SEO is built into the generation pipeline itself. This document covers technical SEO, content SEO, local SEO, and ongoing monitoring -- all automated through OpenClaw's tooling and your existing DataForSEO/Serper integrations.

## Technical SEO (Automated at Build Time)

### Meta Titles and Descriptions

Every page gets a unique, keyword-optimized meta title and description generated by AI.

**Title formula by page type:**

| Page Type | Formula | Example |
|-----------|---------|---------|
| Homepage | `{Service} in {City} | {Business Name}` | `Plumber in Austin | Smith & Sons Plumbing` |
| Service page | `{Service Name} in {City} - {Business Name}` | `Drain Cleaning in Austin - Smith & Sons Plumbing` |
| About page | `About {Business Name} - {City} {Service} Since {Year}` | `About Smith & Sons - Austin Plumber Since 2014` |
| Contact page | `Contact {Business Name} - {City}, {State}` | `Contact Smith & Sons Plumbing - Austin, TX` |
| Blog post | `{Post Title} | {Business Name} Blog` | `5 Signs You Need a Water Heater | Smith & Sons Blog` |
| Location page | `{Service} in {Neighborhood/City} | {Business Name}` | `Plumber in Round Rock | Smith & Sons Plumbing` |

**Title rules:**
- 50-60 characters maximum (Google truncates at ~60)
- Primary keyword near the beginning
- Business name at the end (brand recognition)
- City/location included for local SEO
- No keyword stuffing or pipe separators overuse

**Description rules:**
- 150-160 characters maximum
- Include primary keyword naturally
- Include a call-to-action ("Call today", "Free estimate", "Book online")
- Include a differentiator (years in business, rating, guarantee)
- Every page description must be unique

**Implementation:**
```astro
---
// BaseLayout.astro
const { title, description, canonical } = Astro.props;
---
<head>
  <title>{title}</title>
  <meta name="description" content={description} />
  <link rel="canonical" href={canonical || Astro.url.href} />
  <meta property="og:title" content={title} />
  <meta property="og:description" content={description} />
  <meta property="og:type" content="website" />
  <meta property="og:url" content={Astro.url.href} />
  <meta property="og:image" content={ogImage} />
  <meta name="twitter:card" content="summary_large_image" />
</head>
```

### Canonical URLs

Every page includes a canonical URL to prevent duplicate content issues:

- Homepage: `https://smithplumbing.com/`
- Service page: `https://smithplumbing.com/services/drain-cleaning/`
- Blog post: `https://smithplumbing.com/blog/when-to-call-plumber/`

**Handling duplicates:**
- www vs non-www: redirect to canonical (non-www preferred)
- HTTP vs HTTPS: redirect to HTTPS
- Trailing slash consistency: enforce trailing slash or no trailing slash (pick one)
- Pagination: `rel="next"` and `rel="prev"` for paginated blog

### Image Optimization

**Automated pipeline for every image:**

1. **Format conversion:** All images converted to WebP (with JPEG fallback for old browsers)
2. **Responsive sizing:** Generate multiple sizes (640w, 768w, 1024w, 1280w, 1920w)
3. **Lazy loading:** All below-fold images use `loading="lazy"` attribute
4. **Priority loading:** Hero image and LCP image use `loading="eager"` and `fetchpriority="high"`
5. **Alt text:** AI-generated descriptive alt text for every image
6. **Dimensions:** Explicit width/height attributes to prevent layout shift (CLS)
7. **Compression:** Quality 80-85 (optimal quality/size tradeoff)

**Implementation with Astro:**
```astro
---
import { Image } from 'astro:assets';
import heroImage from '../assets/hero.jpg';
---
<Image
  src={heroImage}
  alt="Smith & Sons plumber repairing a kitchen sink in an Austin home"
  widths={[640, 768, 1024, 1280, 1920]}
  formats={['webp', 'jpeg']}
  loading="eager"
  class="w-full h-[600px] object-cover"
/>
```

### Core Web Vitals Optimization

**Largest Contentful Paint (LCP) -- target < 2.5s:**
- Preload hero image with `<link rel="preload">`
- Use `fetchpriority="high"` on LCP element
- Inline critical CSS (above-fold styles)
- Minimize render-blocking resources
- Use CDN for assets (Vercel's edge network handles this)

**First Input Delay (FID) / Interaction to Next Paint (INP) -- target < 200ms:**
- Minimal JavaScript (Astro ships zero JS by default)
- Defer non-critical scripts
- No long-running synchronous tasks
- Event handlers respond immediately

**Cumulative Layout Shift (CLS) -- target < 0.1:**
- Explicit image dimensions (width/height or aspect-ratio CSS)
- No dynamic content above the fold that loads late
- Font loading with `font-display: swap` and preloaded font files
- Avoid inserting content above existing content (no late-loading banners)

For each client, OpenClaw performs automated keyword research:

**Seed keyword generation:**
```
Input: business_category = "plumber", city = "Austin", state = "TX"

Generated seed keywords:
- "plumber austin tx"
- "plumber near me" (location set to Austin)
- "emergency plumber austin"
- "drain cleaning austin"
- "[each service] austin"
```

**DataForSEO keyword expansion:**
```
API call: keywords_for_site
Input: domain or seed keywords + location
Output:
- Related keywords with search volume
- Keyword difficulty scores
- CPC data (indicates commercial intent)
- SERP features present (maps, featured snippets, etc.)
```

**Keyword selection logic:**
1. Filter by search volume (>50 monthly searches)
2. Filter by difficulty (<40 for new sites, <60 for established)
3. Prioritize keywords with local intent
4. Prioritize keywords with commercial intent (high CPC)
5. Group keywords by topic cluster (map to pages)

### Content Structure

**H1/H2/H3 hierarchy enforced on every page:**

```
H1: One per page, includes primary keyword
  H2: Main sections (3-6 per page)
    H3: Subsections under each H2
      P: Body content with natural keyword inclusion
```

**Example for drain cleaning service page:**
```
H1: Professional Drain Cleaning in Austin, TX
  H2: Our Drain Cleaning Services
    H3: Kitchen Drain Cleaning
    H3: Bathroom Drain Cleaning
    H3: Main Sewer Line Cleaning
    H3: Commercial Drain Cleaning
  H2: When to Call a Drain Cleaning Professional
    H3: Warning Signs of a Clogged Drain
    H3: Why DIY Solutions Can Make It Worse
  H2: Our Drain Cleaning Process
  H2: Drain Cleaning Cost in Austin
  H2: Frequently Asked Questions
  H2: Service Areas
```

**Internal linking strategy:**
- Every service page links to related services
- Homepage links to all main service pages
- Blog posts link to relevant service pages
- Contact page linked from every CTA
- Service area pages interlink with service pages

### Local SEO

**City/neighborhood targeting:**
- Create location-specific pages for each service area
- URL structure: `/services/drain-cleaning/round-rock/`
- Each location page has unique content (not duplicated with city name swapped)
- Include local landmarks, neighborhoods, zip codes naturally in content

**NAP consistency:**
- Business name, address, phone number identical across:
  - Website header/footer
  - Contact page
  - Structured data
  - Google Business Profile
  - All directory listings
- Any inconsistency hurts local ranking

**Service pages per service:**
- Each service gets its own URL and page
- `/services/drain-cleaning/`
- `/services/water-heater-repair/`
- `/services/pipe-repair/`
- Each page targets specific keywords and provides detailed, unique content
- Minimum 500 words per service page

## Monitoring and Ongoing SEO

### Periodic SEO Audit

Run automated SEO audits via DataForSEO on a schedule:

**Weekly checks:**
- Core Web Vitals (has site performance degraded?)
- Uptime (is site accessible?)
- SSL certificate validity
- Google Search Console data (if connected): impressions, clicks, position

**Monthly checks:**
- Full on-page SEO audit (DataForSEO)
- Keyword ranking tracking (are target keywords moving up or down?)
- New backlinks detected
- Technical issues scan (broken links, 404s, redirect chains)
- Competitor ranking comparison

**Quarterly checks:**
- Content freshness audit (are blog posts outdated?)
- New keyword opportunities (DataForSEO keyword gap analysis)
- Local citation audit (NAP consistency across directories)
- Schema markup validation

### Alert System

Set up automated alerts for critical SEO changes:

| Alert | Condition | Action |
|-------|-----------|--------|
| Site down | Uptime check fails | Immediate notification |
| Speed degradation | LCP > 4s | Investigate and fix |
| Ranking drop | Primary keyword drops >5 positions | Review and report |
| New 404 errors | Crawl finds broken pages | Fix or redirect |
| SSL expiring | Certificate expires in <14 days | Renew (usually auto-renew) |
| Manual action | Google Search Console penalty | Urgent review |

### Competitor SEO Comparison

Track how client sites perform against local competitors:

**DataForSEO competitor analysis:**
```
For each client:
1. Identify top 5 competitors (same service, same city)
2. Track shared keywords: who ranks higher?
3. Track competitor backlinks: new link opportunities?
4. Track competitor content: are they publishing more?
5. Monthly report: client position vs competitors
```

**Report format:**
