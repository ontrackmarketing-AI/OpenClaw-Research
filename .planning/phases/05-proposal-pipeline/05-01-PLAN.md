**Create `src/proposals/pipeline.ts`** -- End-to-end orchestrator:

- Import all proposal modules: analyzer, discovery-form, gamma-client, assembler, state
- Import `logAction` from `../notion/action-log.js`
- Import `sendProposalPreview` from `./telegram-handlers.js`
- Export `runProposalPipeline(options: ProposalPipelineOptions, sessionId: string, bot: Bot, chatId: string | number): Promise<ProposalState>`:

  **Step 1: Create proposal record**
  - Generate UUID for proposal ID (use `crypto.randomUUID()`)
  - Call `createProposal` with initial state (status: 'analyzing', trigger source from options)

  **Step 2: Analyze transcript**
  - Call `analyzeForProposal(options.transcriptText, sessionId)`
  - Update proposal: status='outline_ready', meetingAnalysis=JSON.stringify(analysis)
  - Log to Notion action log: type='proposal-generated', action='Meeting analyzed for {company}'

  **Step 3: Generate discovery form (unless skipDiscovery)**
  - If `!options.skipDiscovery && !options.discoveryResponses`:
    - Call `generateDiscoveryForm(analysis, sessionId)`
    - Update proposal: status='discovery_sent', discoveryForm=JSON.stringify(form)
    - Send discovery form summary to Telegram (formatted as MarkdownV2) for operator to create and send
    - Return proposal in 'discovery_sent' state -- pipeline pauses here until discovery responses arrive
  - If `options.discoveryResponses`:
    - Update proposal: status='discovery_received', discoveryResponses=JSON.stringify(options.discoveryResponses)

  **Step 4: Assemble deck content and generate Gamma presentation**
  - Call `assembleDeckContent(analysis, options.discoveryResponses)`
  - Update proposal: status='generating'
  - Call `generatePresentation(inputText, { themeId: options.themeId, numCards: 12, textTone: 'professional, confident, data-driven', textAudience: \`${options.industry || analysis.prospectInfo.industry} business owner\`, imageSource: 'pexels' })` -- use pexels for drafts to save Gamma credits; switch to aiGenerated on operator request
  - Update proposal: status='preview_sent', gammaGenerationId, gammaUrl

  **Step 5: Send preview to Telegram for HITL approval**
  - Call `sendProposalPreview(proposal, bot, chatId)` which formats the message and uses inline Approve/Edit/Reject buttons
  - Log to Notion: type='proposal-generated', action='Proposal preview sent for {company}'
  - Return proposal in 'preview_sent' state

  **Error handling:** Wrap each step in try/catch. On failure, update proposal status remains at last successful state. Log error to stderr and Notion. Send error notification to Telegram: "Proposal generation failed for {company}: {error.message}".
