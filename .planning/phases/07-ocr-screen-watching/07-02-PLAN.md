**~/.openclaw/src/screen/query.ts:**
Implement the screen_recall query tool:

- `createSupabaseClient()` -- import from `./embed-worker.js` (reuse, don't duplicate)
- `screenRecall(query: string, options?: { timeStart?: string; timeEnd?: string; filterApp?: string; limit?: number }): Promise<ScreenSearchResult[]>` -- the main query function:
  1. Create Supabase client
  2. Generate embedding for the query text via `generateEmbedding(query)` (from embed-worker)
  3. Call the `search_screen_captures` RPC function with parameters: `query_text: query`, `query_embedding: embedding`, `match_threshold: 0.7`, `match_count: options.limit ?? 10`, plus optional `time_start`, `time_end`, `filter_app`
  4. Return results as `ScreenSearchResult[]`
  5. On any error (Supabase down, Ollama down), log structured error and return empty array
  6. Log query metadata: `{ component: 'screen-query', action: 'screen_recall', query_length, result_count, elapsed_ms }`

- `getRecentActivity(minutes: number = 120): Promise<ScreenContextSummary | null>` -- for check-in enrichment:
  1. Create Supabase client
  2. Query `screen_captures` from last `minutes` minutes, ordered by `captured_at DESC`, limit 50
  3. Extract unique `app_name` values (filter nulls) into `recentApps`
  4. Build a brief `summary` string: "Working in {app1}, {app2}, {app3} over the last {N} minutes. {captureCount} screen snapshots captured."
  5. If the most recent capture has a `window_title`, append: "Most recently: {window_title}"
  6. Return as `ScreenContextSummary` or null if no captures in the time window
  7. On any error, log and return null (graceful degradation)

- `formatScreenResults(results: ScreenSearchResult[], maxChars: number = 3000): string` -- formats results for LLM consumption:
  1. For each result: `"[{timestamp}] {app_name} - {window_title}\n{ocr_text_truncated}"`
  2. Truncate individual OCR text at 500 chars
  3. Truncate total output at `maxChars`
  4. Include result count header: "Found {N} screen captures matching your query:"
