**openclaw-capture/capture/privacy.py:**
Implement the privacy-first filter with these functions:
- `load_config(config_path: str) -> dict` -- load YAML config, cache it
- `should_skip(app_name: str, window_title: str, config: dict) -> bool` -- returns True if:
  1. `app_name` matches any entry in `excluded_apps` or `excluded_apps_personal` (case-insensitive)
  2. `window_title` matches any `excluded_title_patterns` (use fnmatch, case-insensitive)
  3. `window_title` contains any `incognito_patterns` substring (case-insensitive)
- `scrub_sensitive_text(ocr_text: str, config: dict) -> tuple[str, bool]` -- returns `(cleaned_text, was_scrubbed)`:
  1. Check each regex in `sensitive_text_patterns` against the OCR text
  2. If any match: replace the match with `[REDACTED]` and set `was_scrubbed = True`
  3. Return the cleaned text and whether any scrubbing occurred
  4. Log a WARN if scrubbing happened (but do NOT log the sensitive content itself)

**openclaw-capture/capture/dedup.py:**
Implement content hash deduplication:
- `compute_hash(ocr_text: str) -> str` -- SHA-256 hash of the OCR text
- `is_duplicate(content_hash: str, db_cursor) -> bool` -- check if hash exists in last 5 minutes of captures in local SQLite
- Purpose: If screen text hasn't changed, skip storage. Reduces storage by 40-60%.

**openclaw-capture/capture/daemon.py:**
Implement the main capture loop:
- `get_active_window() -> tuple[str, str]` -- returns `(app_name, window_title)` using `pygetwindow.getActiveWindow()`; returns `("unknown", "unknown")` if detection fails
- `capture_screen(max_width: int) -> PIL.Image` -- uses `mss.mss()` to grab primary monitor, converts BGRA to RGB via Pillow, downscales if width > `max_width`
- `ocr_image(image: PIL.Image) -> str` -- runs `pytesseract.image_to_string(image)`, strips whitespace
- `init_local_db(db_path: str)` -- creates SQLite database with table:
  ```sql
  CREATE TABLE IF NOT EXISTS captures (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    captured_at TEXT NOT NULL,
    app_name TEXT,
    window_title TEXT,
    ocr_text TEXT NOT NULL,
    content_hash TEXT NOT NULL,
    image_path TEXT,
    synced INTEGER DEFAULT 0,
    created_at TEXT DEFAULT (datetime('now'))
  );
  CREATE INDEX IF NOT EXISTS idx_captures_synced ON captures(synced);
  CREATE INDEX IF NOT EXISTS idx_captures_hash ON captures(content_hash);
  CREATE INDEX IF NOT EXISTS idx_captures_time ON captures(captured_at DESC);
  ```
- `run_capture_loop(config: dict, db_path: str, pause_event: threading.Event)` -- main loop:
  1. Check `pause_event` -- if set, sleep and continue (supports Telegram pause/resume)
  2. Get active window via `get_active_window()`
  3. Call `should_skip()` -- if True, sleep and continue (NO screenshot taken)
  4. Capture screen via `capture_screen()`
  5. Run OCR via `ocr_image()`
  6. If OCR text is empty or under 10 chars, skip (blank/lock screen)
  7. Run `scrub_sensitive_text()` on OCR output; if entirely redacted, skip
  8. Compute content hash; check `is_duplicate()` -- if True, skip
  9. Post-capture privacy check: call `get_active_window()` again. If now different app AND the new app is in exclusions, discard the capture (race condition mitigation per research Pitfall 6)
  10. Save screenshot to local disk (date-organized: `screenshots/YYYY-MM-DD/HH-MM-SS.png`)
  11. Insert row into local SQLite with `synced=0`
  12. Sleep for `capture_interval_seconds`
  13. Wrap entire loop body in try/except with continue -- never let the loop break

**openclaw-capture/sync/supabase_sync.py:**
Implement the sync service:
- `sync_unsynced_captures(config: dict, db_path: str) -> int` -- fetches up to 50 rows where `synced=0`, POSTs to Supabase REST API via httpx:
  - URL: `{supabase_url}/rest/v1/screen_captures`
  - Headers: `apikey` and `Authorization: Bearer {service_role_key}`, `Content-Type: application/json`, `Prefer: return=minimal`
  - Body: array of `{captured_at, source_device: 'windows_desktop', monitor_index: 0, window_title, app_name, ocr_text, content_hash}`
  - On success (201): mark rows as `synced=1` in local SQLite
  - On failure: log error, leave `synced=0` for retry next cycle
  - Returns count of synced rows
- `run_sync_loop(config: dict, db_path: str)` -- runs `sync_unsynced_captures()` every `sync_interval_seconds`, wrapped in try/except with continue

**openclaw-capture/sync/offline_queue.py:**
Implement offline resilience:
- `get_unsynced_count(db_path: str) -> int` -- count of `synced=0` rows
- `cleanup_old_captures(db_path: str, retention_days: int)` -- delete local captures older than retention_days, also delete corresponding screenshot files from disk

**openclaw-capture/main.py:**
Entry point that:
1. Loads config from `config/screen_capture.yaml`
2. Initializes local SQLite database at `~/.openclaw-capture/captures.db`
3. Creates `pause_event` and `shutdown_event` threading.Events
4. Starts capture loop thread (`daemon.run_capture_loop`)
5. Starts sync loop thread (`supabase_sync.run_sync_loop`)
6. Starts command poller thread (polls Supabase `screen_commands` table every 10s for pause/resume/delete commands from Telegram relay, executes them)
7. Starts system tray on main thread (`tray_app.run_tray`)
8. On quit: sets shutdown_event, joins all threads, closes database

**Important implementation notes:**
- All file paths use `pathlib.Path` for Windows compatibility
- Screenshots directory: `~/.openclaw-capture/screenshots/`
- Database path: `~/.openclaw-capture/captures.db`
- Logging uses Python `logging` module with structured JSON format to both console and `~/.openclaw-capture/daemon.log`
- The command poller fetches `status='pending'` commands from Supabase `screen_commands` table, executes them (pause sets pause_event, resume clears it, delete removes captures from specified time range), then updates the command status to `'executed'`
