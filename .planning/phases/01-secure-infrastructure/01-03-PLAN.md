**Cost tracker module (`~/.openclaw/src/cost/tracker.ts`):**

Use `better-sqlite3` npm package for SQLite access. Initialize the database at `~/.openclaw/data/cost-tracker.db` with tables:

```sql
CREATE TABLE IF NOT EXISTS usage (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  timestamp TEXT NOT NULL,
  session_id TEXT NOT NULL,
  model TEXT NOT NULL,
  input_tokens INTEGER DEFAULT 0,
  output_tokens INTEGER DEFAULT 0,
  cost_usd REAL DEFAULT 0,
  tool_calls INTEGER DEFAULT 0
);

CREATE TABLE IF NOT EXISTS sessions (
  session_id TEXT PRIMARY KEY,
  started_at TEXT NOT NULL,
  tool_call_count INTEGER DEFAULT 0,
  total_cost_usd REAL DEFAULT 0
);

CREATE TABLE IF NOT EXISTS circuit_breaker_events (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  timestamp TEXT NOT NULL,
  trigger TEXT NOT NULL,
  current_value TEXT NOT NULL,
  limit_value TEXT NOT NULL,
  session_id TEXT
);
```

Implement these functions:
1. `initDB(dbPath?: string): Database` -- Create/open SQLite DB, run migrations
2. `checkLimits(sessionId: string): LimitCheckResult` -- Read counters, compare against limits. Returns `{ allowed, reason, current, limits }`. This is called BEFORE every Anthropic API call.
3. `recordUsage(record: UsageRecord): void` -- Insert usage row and update session counters
4. `getMonthlySpend(): number` -- Sum cost_usd for current calendar month
5. `getSessionStats(sessionId: string): { tool_calls: number, duration_minutes: number, cost_usd: number }`
6. `logCircuitBreakerEvent(trigger: string, currentValue: string, limitValue: string, sessionId: string): void` -- Record the event and emit structured JSON log

**Graceful degrade behavior (per user decision):**
When `checkLimits` returns `allowed: false`:
- The agent COMPLETES its current action (does not abort mid-action)
- The agent STOPS accepting new work
- A circuit breaker event is logged with: which limit was hit, current value, limit value, timestamp, session_id

**Reconciliation module (`~/.openclaw/src/cost/reconcile.ts`):**

Implement `reconcileCosts(adminApiKey: string): { drifted: boolean, local: number, api: number, corrected: boolean }`:
1. Call Anthropic Usage API: `GET https://api.anthropic.com/v1/organizations/usage_report/messages` with headers `x-api-key: <admin_key>`, `anthropic-version: 2023-06-01`
2. Parse response to get monthly spend
3. Compare against local `getMonthlySpend()`
4. If drift > configured threshold (default 5%): update local counter to match API
5. Log reconciliation result

If admin API key is not available (env var not set), log a warning and skip reconciliation. The system still works with local-only tracking.

**Context guard module (`~/.openclaw/src/safety/context-guard.ts`):**

Implement:

1. `loadDirectives(configPath?: string): DirectiveConfig` -- Load and parse the YAML config

2. `getPinnedDirectives(config: DirectiveConfig): string` -- Format directives as a block for injection into system prompt:
   ```
   [PINNED -- DO NOT SUMMARIZE]
   1. All RED-tier and YELLOW-tier actions are BLOCKED. Log and refuse. No exceptions.
   2. DELETE operations ALWAYS require HITL approval. This rule never relaxes. No exceptions.
   3. Cost limits enforced: $50/month Anthropic cap, 50 tool calls per session, 30-minute session timeout. Stop on breach.
   4. Never send external messages autonomously. All external communication requires explicit human approval.
   [END PINNED]
   ```

3. `verifyDirectives(contextText: string, config: DirectiveConfig): VerificationResult` -- Check that each directive's keywords are present in the context. Use a ROBUST matching strategy (per Pitfall 7 in research): check for the presence of key phrases from each directive, NOT exact string matching, because summarization may alter whitespace/formatting.
   - For each directive, check that at least 2 of its keywords appear in the context
   - If ANY directive has fewer than 2 keyword matches: `all_present: false`, list the directive ID in `missing`

4. `shouldCheckpoint(turnCount: number, config: DirectiveConfig): boolean` -- Returns true when `turnCount % checkpoint_interval === 0`

5. `shouldVerify(turnCount: number, config: DirectiveConfig): boolean` -- Returns true when `turnCount % verification_interval === 0`

6. `handleVerificationFailure(result: VerificationResult): void` -- Log which directives were lost, at which turn count. Emit a HALT signal (structured JSON log with `level: "CRITICAL"`, `action: "SESSION_HALT"`, `reason: "pinned directive missing"`, `missing_directives: result.missing`).

**Emergency stop procedure:**

Create `~/.openclaw/docs/emergency-stop.md`:
```markdown
# Emergency Stop Procedure

## Quick Stop (< 30 seconds)
docker compose -f ~/.openclaw/docker-compose.yml stop

This immediately:
- Stops all containers (PostgreSQL, Redis, Qdrant, n8n)
- Cuts agent access to ALL external services (keys are behind n8n proxy)
- Preserves all data (bind mounts remain intact)

## Full Shutdown (< 1 minute)
~/.openclaw/scripts/emergency-stop.sh

## Resume After Stop
docker compose -f ~/.openclaw/docker-compose.yml up -d

## When to Use
- Agent behaving unexpectedly
- Suspected security breach
- Cost circuit breaker failed to trigger
- Any situation requiring immediate agent isolation

## Key Revocation (< 5 minutes)
If the stop is due to a security breach:
1. Stop containers (above)
2. Rotate n8n encryption key in ~/.openclaw/.env
3. Regenerate all API credentials in n8n credential store
4. Review audit logs: docker logs openclaw-n8n
```
